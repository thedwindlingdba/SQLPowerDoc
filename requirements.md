# Requirements for SQLPowerShell DOC

### Requirements

- RSAT Tools Windows 7...10
- **PowerShell:** **7+** recommended for development and tests; legacy scripts may still run on Windows PowerShell 5.1 where noted.
- **Pester 5.x** (contributors running tests): `Install-Module Pester -MinimumVersion 5.0.0 -MaximumVersion 5.999999 -Scope CurrentUser -Force`
- SSMS SQL Server Management Studio / Sql Server Management Objects (SMO)

### Login 
* with SQL Server SYSADMIN Rights
